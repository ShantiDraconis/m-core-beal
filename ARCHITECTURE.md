# M-Core Beal research architecture

Scientific status: research scaffold, not a proof of Beal. Beal is not a Clay Millennium problem.

Pipeline: Official prize statement → Specification → integer/exponent objects → factorization → Signature → discrete boundary atlas → ProofDAG → AttackDAG → Bridges → Adapters → Frontier → Endpoint → audit → reproduction.

Signature: g_Beal(A,B,C)=gcd(A,gcd(B,C)); target >1 under A^x+B^y=C^z, positive integers and x,y,z>2. Preferred endpoint: ∃ prime p dividing A,B,C. Counterexample obstruction is equation ∧ exponent constraints ∧ gcd=1, after proving gcd/common-prime equivalence.

Boundary protocol is arithmetic/discrete: exponent boundary 2/3, positivity/zero boundary, prime-support changes and sequences of candidate solutions. No literal L’Hôpital or 0/0 is assumed without a naturally derived analytic quotient.

Attack loop checks circular coprimality, pairwise/common gcd confusion, divisibility direction, exponent boundary, zero cases and imported Diophantine results.

Cross-problem relations require explicit certified adapters.
